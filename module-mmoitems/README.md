# FallenStar MMOItems-Modul

Integriert MMOITems in das FallenStar-Framework, sodass beispielsweise Münzen über MMOItems integriert werden. 

## Brainstorms

- FallenStar reserviert Namespaces in MMOItems, beispielsweise in Kategorieren. Wenn FallenStar Kategorien in MMOItems erstellt, erhalten diese den Präfix "FS_ITEMS_". (FS_ITEMS_MINERALIEN , FS_ITEMS_WERKZEUG o.ä.)
- Das Modul braucht korrektes und konsistentes "Bridging" für Spezialitems, die vom FS Framework definiert werden, beispielsweise Münzen. Das heißt, dass eine Münze sowohl über MMOItems-Befehle, als auch über FallenStar-Befehle erzeugt werden kann, ohne dass sich die Items voneinander unterscheiden!
